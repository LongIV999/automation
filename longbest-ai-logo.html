How to Export for Facebook

To use these logos for your Facebook fanpage profile picture:

Method 1: Screenshot

1. Right-click on logo preview
2. "Inspect Element"
3. Screenshot the element
4. Crop to 1:1 ratio (500x500px)

Method 2: Canvas Export

1. Open browser console (F12)
2. Use html2canvas library
3. Export as PNG
4. Resize to 500x500px

Method 3: Recreate

Use these specs in Canva/Figma:
• Size: 500x500px
• Font: Inter (800 weight)
• Colors: #1a1a1a, #d97757
